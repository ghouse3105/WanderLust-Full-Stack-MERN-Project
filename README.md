# 🌍 WanderLust – Full Stack MERN Project

A full-stack travel accommodation platform inspired by **Airbnb**, built using the **MERN Stack**. WanderLust allows users to discover, create, edit, and manage property listings while providing a secure authentication system and a seamless booking-style experience.

> **Note:** This project is developed for educational and portfolio purposes only and is not affiliated with Airbnb.

---

## 🚀 Features

### 👤 User Authentication
- User Registration
- Secure Login & Logout
- Password Encryption
- Session-based Authentication
- Authorization for Protected Routes

### 🏡 Property Listings
- Browse all listings
- View listing details
- Add new listings
- Edit existing listings
- Delete listings
- Upload property images

### ⭐ Reviews & Ratings
- Add reviews
- Delete reviews

### 📍 Property Information
- Property Title
- Description
- Price
- Country
- Location
- Images

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/ghouse3105/WanderLust-Full-Stack-MERN-Project.git
```

## Navigate to Project

```bash
cd WanderLust-Full-Stack-MERN-Project
```

## Install Dependencies

```bash
npm install
```

## Configure Environment Variables

Create a `.env` file in the root directory.

```env
ATLASDB_URL=your_mongodb_connection_string

SECRET=your_secret_key

CLOUD_NAME=your_cloudinary_name

CLOUD_API_KEY=your_cloudinary_api_key

CLOUD_API_SECRET=your_cloudinary_api_secret
```

## Start Application

```bash
npm start
```

The application will run on:

```
http://localhost:3000
```
