This is a full-stack web application built using modern web development technologies, featuring secure user authentication (Login & Sign Up). The project follows a client–server architecture with a responsive and interactive user interface.

Frontend

Developed using HTML, CSS, and JavaScript

Responsive and user-friendly UI

Login and Sign Up forms with client-side validation

Backend

Built with Node.js and Express.js

RESTful APIs for application logic

Secure authentication handling for user Login and Sign Up

Server-side validation and error handling

Database

Uses MongoDB for scalable data storage

Stores user credentials and application data

Supports CRUD operations

Features

User Registration (Sign Up)

User Authentication (Login)

Secure data handling

Frontend–backend integration

REST API architecture

This project demonstrates essential full-stack development concepts, including authentication, API development, database integration, and frontend–backend communication.
